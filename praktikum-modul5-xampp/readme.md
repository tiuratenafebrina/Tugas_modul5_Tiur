## Cara menjalankan
1. Pindahkan folder ke `C:\xampp\htdocs\`.
2. Start Apache dan MySQL di XAMPP.
3. Buka `http://localhost/praktikum-modul5-xampp/crud_php_mysql/generate.php` (sekali saja).
4. Login di `crud_php_mysql/login.php` dengan username `admin` dan password `adminmahasiswa`.
